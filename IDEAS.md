# Ideas (post-v1)

Not in scope for v1. Mostly Hevy features worth considering later, roughly by value.

- **Routines** (Hevy's core): saved workouts to start from; "Start routine" pre-fills exercises
  and sets from last time. Could link to plan weekdays (Mon = Push, …).
- **RPE** per set.
- **Rest-timer alert in background** (needs web push → a server).
- **Supersets**: group exercises.
- **Replace exercise keeps sets**; per-exercise rest set inside a routine.
- **Exercise types**: duration (Plank), weighted/assisted bodyweight, distance.
- **Per-exercise notes** that persist across workouts (seat height, grip).
- **Stats**: weekly sets per muscle group, training streak, muscle distribution.
- **Plate calculator / warm-up set generator.**
- **Body weight / measurements tracking.**
